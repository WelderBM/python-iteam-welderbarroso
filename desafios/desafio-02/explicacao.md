## Resposta à Pergunta Obrigatória

> Por que é necessário usar `float()` ao capturar peso e altura com `input()`? O que aconteceria se usássemos `int()` para a altura `1.75`?

_(float é necessário para números com vírgulas, números com casas decimais; se usar o int para receber o número 1.75, vai dar erro, pois 1.75 é um número que tem 2 casas decimais.)_
